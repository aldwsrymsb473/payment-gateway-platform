# منصة مدفوعات رحاتي

نواة آمنة لخدمة **ملفي راحتي للشقق المخدومة الفندقية**، مبنية بـ Node.js وExpress، وتستخدم صفحات الدفع المستضافة من مزود الدفع لتجنب تخزين بيانات البطاقات داخل النظام.

> هذه نسخة تأسيسية قابلة للتطوير وليست ترخيصاً لتقديم خدمات معالجة المدفوعات للغير. قبول المدفوعات يتطلب حساب تاجر موثقاً، عقداً مع مزود دفع مرخص، والالتزام بمتطلبات المملكة العربية السعودية وPCI DSS.

## التشغيل المحلي

```bash
npm install
cp .env.example .env
npm run dev
```

ثم افتح `http://localhost:3000/health`.

## الإعدادات المطلوبة

1. أنشئ حساباً تجارياً لدى مزود دفع يدعم نشاط الإقامة والسعودية (مثل Stripe أو بوابة سعودية مرخصة، بحسب الأهلية المتاحة).
2. ضع مفاتيح الاختبار في `.env` فقط، ولا ترفع الملف إلى GitHub.
3. فعّل العملة `SAR` وطرق الدفع المناسبة من لوحة مزود الدفع.
4. اضبط عنوان webhook على:
   `https://YOUR_DOMAIN.example/api/payments/webhook`
5. استخدم HTTPS ونطاقاً موثقاً قبل الإنتاج.

## نقاط API

- `GET /health` فحص الخدمة.
- `POST /api/payments/checkout` إنشاء جلسة دفع مستضافة.
- `POST /api/payments/webhook` استقبال أحداث الدفع والتحقق من توقيعها.

مثال إنشاء جلسة:

```json
{
  "bookingId": "booking-123",
  "amountHalalas": 25000,
  "currency": "sar",
  "customerEmail": "guest@example.com"
}
```

## الأمان والخصوصية

- لا ترسل رقم البطاقة أو CVV إلى خادمك؛ استخدم صفحة الدفع المستضافة.
- لا تضع مفاتيح API أو بيانات الحساب البنكي أو السجل التجاري في GitHub أو المحادثات.
- بما أن المستودع عام، اجعله خاصاً أو احذف أي بيانات حساسة إن أضيفت بالخطأ، ثم دوّر المفاتيح فوراً.
- خزّن الحجوزات وحالات الدفع في قاعدة بيانات مع سجل تدقيق، وأضف مصادقة وصلاحيات قبل الإطلاق.
- استخدم بوابة دفع مرخصة في السعودية، وراجع المتطلبات النظامية والضريبية وسياسة الخصوصية مع مستشار مختص.

## مهم

لا يوجد مزود واحد يضمن قبول «كل» طرق الدفع في كل الدول. التغطية تعتمد على بلد التاجر، نوع النشاط، العملة، وموافقة مزود الدفع. يمكن إضافة PayPal أو بوابة محلية لاحقاً خلف واجهة موحدة بعد التحقق من أهلية الحسابات.

## النشر

يمكن نشر الخدمة على Render أو Railway أو Fly.io أو خادم VPS. أضف متغيرات البيئة نفسها في إعدادات المنصة، ولا تستخدم مفاتيح الاختبار في الإنتاج.
